# SlopCop branding

The Gumshoe mark and favicon match the public slopcop.com branding from
`bifrost-service` revision `de272286`. The mark geometry is unchanged; its
ink follows the documentation theme and the hat band stays `#ee3c42`.

The header uses the same Redaction 20 Bold wordmark subset and spacing as
the public landing page. The subset and its SIL Open Font License are in
`public/fonts/Redaction_20-Bold-wordmark.woff2` and `public/fonts/Redaction-OFL.txt`.
Other documentation typography is unchanged.
The social card uses outlines from that same subset for reproducible rendering.
